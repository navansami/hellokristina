# Serbian flag

`serbia.jpg` is the official RGB state flag artwork linked by the Republic of Serbia Ministry of Foreign Affairs, downloaded on 2026-11-01. The original artwork is bundled without modification.

- Ministry source: https://msp.gov.rs/en/node/4541
- National Assembly artwork: https://www.parlament.gov.rs/upload/images/content/amblems/drzavna%20zastava%20RS%20rgb.jpg

The app decodes it at a small cached width for the course selector and profile icons.
